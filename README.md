# Analytics Telegram Bot (Data Pipeline)

## Описание проекта
Telegram-бот для автоматизации бизнес-аналитики. Проект решает задачу оперативного мониторинга метрик отдела B2B-продаж (поступление лидов, распределение по менеджерам, конверсия в успешные сделки). 

## Стек технологий
* **Python (aiogram 3.x)** — асинхронный фреймворк для взаимодействия с Telegram API.
* **SQLite3** — локальная база данных для хранения поступающих заявок и статусов сделок.
* **Pandas** — агрегация данных, группировка выручки по менеджерам и расчет конверсии.
* **Matplotlib** — автоматическая генерация графиков (bar chart).

## Архитектура решения (ETL)
1. **Сбор данных:** Бот инициализирует реляционную базу данных и логирует заявки (в проекте реализован мок-генератор для демонстрации).
2. **Аналитика:** По запросу происходит выгрузка данных из SQLite в DataFrame, где данные фильтруются по статусу «Успешно» и группируются.
3. **Визуализация:** Matplotlib строит график «на лету» и отправляет пользователю через Telegram API вместе с текстовой сводкой по конверсии.
